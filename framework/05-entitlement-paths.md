# 05 — Entitlement Paths

**The path is a choice variable, not an input.** The same parcel can often be entitled through several legal routes, and each route faces a different veto stack. The engine should optimize over (state × county × path), not (state × county). California Forever demonstrated this empirically: after the county general-plan-amendment-by-ballot route failed, they pivoted to annexation through Suisun City — swapping a county-electorate referendum for a municipal council + LAFCO + likely litigation stack.

## The four paths

### 1. County-level entitlement (the default assumption)

Rezone/PUD/development agreement with the county for unincorporated land.

- **Veto stack:** county commission → (in some states) county electorate via referendum → state environmental review → litigation.
- **Best when:** county is a Boom County ([topology](03-county-screen.md)), state vests early, no referendum reach.

### 2. Annexation into an existing municipality

Contract annexation with a small, willing town; entitlements via municipal council.

- **Veto stack:** town council → boundary commission if the state has one → possibly municipal electorate → litigation.
- **Best when:** a tiny municipality near the site wants the tax base; contractual annexation terms can embed vested entitlements (contract-clause durability).
- **Watch:** ETJ states (e.g., NC) — a *hostile* nearby municipality can also reach you this way.

### 3. Incorporation of a new municipality

Become the jurisdiction.

- **Veto stack:** state incorporation statute requirements (population/density minimums, petition thresholds) → boundary commission → sometimes county approval → election of the (initially tiny) local population.
- **Best when:** state has permissive incorporation law and you control enough land/residents to win the incorporation vote. Slow; durability arrives late but is then maximal.

### 4. Special district / legislative charter

MUDs (TX), improvement districts, or a bespoke legislative district providing utility powers and partial autonomy.

- **Veto stack:** state legislature or administrative process at formation; **state legislature forever after**.
- **Watch — the Reedy Creek lesson:** a district held at legislative pleasure is durable against local veto but exposed to state political turnover. Apply the [breach test](00-the-question.md#the-breach-test): the surviving version is one whose revocation triggers a compensable taking or enjoinable contract claim.

## Path 0 — Buy already-entitled

The standing alternative to manufacturing entitlements: **acquire land where someone else already purchased durability** — defunct or stalled master-planned communities with live development agreements, base-reuse authority land, large parcels with vested industrial entitlements. If vested rights survive sale (state-specific — verify), this is the only place a cheap durable yes at 10–100x magnitude reliably already exists. Maintain it as a permanent scorecard column and dealflow track, not a fallback.

## Output

The [state screen](02-state-screen.md) enumerates which paths exist in each state and each path's veto stack; the county screen then evaluates the best available path per county. A county scores as well as its *best* path, not its default one.
